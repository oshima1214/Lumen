# iPhone 実機チェックリスト（計画 Task 28）

対象: iPhone（iOS 26 以降）の Safari。公開版（Cloudflare Pages の URL）で確認する。
各項目の「結果」欄に ○ / × とメモを書く。× の項目はスクリーンショットがあると助かります。

| # | 確認すること | 手順 | 期待する結果 | 結果 |
|---|---|---|---|---|
| 1 | GPU の動作 | `/gpu-check/` を開く | `rgba16float` ストレージ書き込み「可」、4096×3072 と 8064×6048 の確保結果、現像時間（目標 33ms 以内）が表示される | |
| 2 | 起動 | トップページを開く | 「WebGPU が使えません」と出ずに一覧画面が出る | |
| 3 | ホーム画面に追加 | 共有 → ホーム画面に追加 → アイコンから起動 | アイコン（金色の絞り）で全画面起動する | |
| 4 | 取り込み（写真アプリ） | ＋ → 写真ライブラリから HEIC を 1 枚 | 取り込まれる。JPEG に変換された場合は案内が出る | |
| 5 | 取り込み（ファイル） | ＋ → ファイルから HEIC / ProRAW（DNG）を 1 枚ずつ | 元の形式のまま取り込まれ、サムネイルが出る | |
| 6 | 48MP | 48MP の HEIF Max / ProRAW を開く | 落ちずに表示される（「解像度を下げて表示しています」が出てもよい） | |
| 7 | 編集の体感 | 露光・彩度スライダーを動かす | 引っかかりなく追従する | |
| 8 | 編集前の表示 | 写真を長押し | 長押し中は編集前に戻る | |
| 9 | ボタンの押しやすさ | 各タブとボタンを押す | 誤タップしにくい（44px 以上） | |
| 10 | 書き出し | 書き出し → 共有シート →「画像を保存」 | 写真アプリに保存され、向き・色が正しい | |
| 11 | 48MP の書き出し | 48MP の写真を原寸で書き出す | 落ちずに完了する | |
| 12 | アプリ切り替え | 編集中に別アプリへ移り、戻る | 表示が復帰する（真っ黒にならない） | |
| 13 | データ保持 | ホーム画面のアイコンから翌日以降に起動 | 取り込んだ写真と編集内容が残っている | |
| 14 | オフライン | 機内モードでホーム画面のアイコンから起動 | アプリが起動し、取り込み済みの写真を編集できる | |
